Editing

Pick a part in the Builder, then click the canvas to place it (R rotates, Esc cancels). Choose Connect, click to start a pipe and click again to finish. Circles along pipes create branches; nearby terminals snap. Red rings mark loose ends. Drag empty space to pan. Drag a part to move it with its pipes; Shift-drag detaches it. Drop a loose two-terminal part onto a highlighted pipe to insert it in series. Crossings do not connect.

Click a switch body to toggle it. A diode is a swing check valve that only opens with forward flow. Click a part or pipe to probe its voltage and current.

What the simulation assumes

Ripple defaults to verified steady state; Transients starts from zero stored energy. Educational switched RLC solver (backward Euler), not SPICE: DC and sine supplies, resistors, capacitors, inductors, 2–4 coupled windings (k = 1 by default), PWM switches and up to eight diodes (forward drop + 0.01 Ω, no reverse current or recovery). Wires are ideal. Leakage mode includes an inspectable primary RC snubber for recognized flyback and forward circuits. Saturation and reverse recovery are not modeled. Floating nodes and interrupted inductor current are reported rather than hidden.

Simulation setup
Timing

Mode

Ideal uses the available course reference or ideal-component dynamics. Ripple displays four verified steady-state cycles with finite L/C ripple; a bounded solve reports failure when it cannot settle. Transients shows startup from zero stored C/L energy (and saved memristor state).

Leakage is experimental and incomplete. Only recognized flyback and reset-forward currently support finite magnetic coupling with an added primary RC snubber. General leakage behavior is not implemented. Unsupported circuits disable Leakage. Selecting Leakage enables Transients by default.

Simulation

Device losses off removes diode voltage drop and switch/diode on-resistance. On uses the component values from Properties (including default diode resistance). This is independent of Transients: losses change component conduction; Transients shows startup. Source, load and snubber resistors stay active in either setting. Ideal mode locks this off; full-bridge boost Ripple requires it on. Reverse recovery, avalanche, saturation and nonlinear Coss are not modeled.

Adds dashed, periodic Ideal course-reference curves to the plots for comparison with the active simulation. It does not change the circuit, animation or selected mode. Available only when a validated course reference exists.

Experimental circuit import

  
Preview an RLC circuit with constant voltage supplies before replacing the current circuit.

  
Supported formats and export instructions
  
LTspice: View → SPICE Netlist; save UTF-8 .cir/.net/.sp or paste text. Supports R, L, C, constant V and one uniform K group per 2–4 windings.

  
KiCad: File → Export → Netlist → KiCad (.net), or kicad-cli sch export netlist --format kicadsexpr. Supports standard Device R/R_Small, C/C_Small/C_Polarized/CP/CP1, L/L_Small and Battery/Battery_Cell, pins 1 and 2. Use a literal voltage for the battery and one net named GND, 0, /GND or /0.

  
Direct .kicad_sch, .asc, XML, semiconductors, models, expressions, controlled/time-varying sources and initial conditions are unsupported. No device is silently skipped or substituted.
